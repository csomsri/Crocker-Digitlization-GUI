# Workspace layout audit

The audit captures all 24 registered pages, the PID/BO/Hybrid sections, Field
Control's six sections, both GA workspaces, a collapsed directory, and navigation
inside a detached Monitoring window: 40 views in total. Screenshots and
`manifest.json` are generated by `tests/PageVisualAudit.py --output <directory>`.
The capture uses simulation and temporary databases; it sends no hardware commands.

## Navigation behavior

- The directory edge arrow collapses left and reopens right, preserving its width.
- `Go to` in the main directory explicitly returns a page to the main workspace.
- `+` opens or raises the existing page's window without constructing another controller.
- Page-owned navigation, including category links and Back, follows the page's current host window.
- When a target is already open in another window, its existing host is raised.
- When a detached host changes pages, its title, current page, close policy, and Workspace action are updated together.
